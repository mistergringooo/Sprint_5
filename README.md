# Sprint_5 — UI-тесты для Stellar Burgers

## Описание
Автотесты для веб-приложения Stellar Burgers. 
Тесты написаны на Python с использованием Selenium WebDriver и pytest.

## Что тестируется
- Регистрация пользователя
- Вход в аккаунт (4 способа)
- Переход в личный кабинет
- Переход из личного кабинета в конструктор
- Выход из аккаунта
- Переключение вкладок конструктора

## Технологии
- Python 3.13
- Selenium
- pytest
- Google Chrome

## Как запустить тесты

1. Установить зависимости:
- pip install selenium pytest

2. Запустить все тесты:
- python -m pytest tests/ -v
